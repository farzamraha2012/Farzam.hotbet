# تحلیل‌گر هات‌بت — نمونه اولیه اندروید

این پروژه یک نمونه اولیه Android Studio است. با تأیید صریح کاربر، صفحه از طریق Android MediaProjection خوانده می‌شود و ML Kit OCR تلاش می‌کند اعداد شبیه ضرایب را از متن قابل مشاهده استخراج کند.

## ساخت و نصب
1. پوشه پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle وابستگی‌ها را دریافت کند.
3. گوشی را با USB وصل کنید و Run را بزنید.
4. داخل برنامه «شروع خواندن خودکار صفحه» را بزنید و مجوز ضبط صفحه اندروید را تأیید کنید.
5. برای پایان کار «توقف» را بزنید.

## محدودیت‌ها
- این نسخه به API یا حساب سایت هات‌بت متصل نیست؛ فقط محتوای قابل مشاهده صفحه را با OCR می‌خواند.
- OCR ممکن است اعداد را اشتباه بخواند یا با اسکرول و تغییر چیدمان، نتایج را جا بیندازد.
- این نسخه آزمایشی است و قبل از استفاده باید روی چیدمان واقعی سایت آزمایش و اصلاح شود.
- آمار گذشته احتمال دور بعد را تعیین نمی‌کند و برنامه سیگنال برد تضمینی نمی‌دهد.
- این فایل ZIP سورس پروژه است، نه APK آماده نصب.

## حریم خصوصی
تصویر در دستگاه پردازش می‌شود و ضبط صفحه فقط بعد از تأیید سیستمی کاربر آغاز می‌شود.
