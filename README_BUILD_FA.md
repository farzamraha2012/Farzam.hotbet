# ساخت نسخه اندروید Galaxy S23 Ultra

این نسخه دارای پنجره شناور قابل جابه‌جایی، نمایش آمار OCR و دکمه توقف است. ابتدا مجوز «نمایش روی برنامه‌های دیگر» را بدهید، سپس اجازه ضبط صفحه را تأیید کنید. پنجره شناور روی بعضی صفحه‌های محافظت‌شده نمایش داده نمی‌شود و تصویر برنامه‌های دارای FLAG_SECURE قابل ضبط نیست.

## ساخت
در Android Studio پوشه پروژه را باز کنید. JDK 17 و Android SDK Platform 35 را نصب کنید. اتصال اینترنت برای دریافت Gradle و وابستگی‌های ML Kit ضروری است.

روی Linux/macOS: `./gradlew assembleDebug`

روی Windows: `gradlew.bat assembleDebug`

خروجی پس از ساخت موفق: `app/build/outputs/apk/debug/app-debug.apk`

**نکته:** فایل `gradle-wrapper.jar` این بسته یک راه‌انداز سبک سازگار با فرمان‌های Gradle است، نه فایل رسمی Gradle Wrapper. توزیع Gradle 8.9 را از نشانی موجود در `gradle-wrapper.properties` دریافت و اجرا می‌کند. در صورت تمایل می‌توانید با `gradle wrapper --gradle-version 8.9` فایل‌های رسمی را جایگزین کنید.

## محدودیت‌های تست
در محیط تولید این بسته Android SDK و دسترسی شبکه برای دانلود Gradle وجود نداشت؛ بنابراین APK تولید نشده و build روی گوشی واقعی تأیید نشده است. برای Android 14/15 ممکن است انتخاب «تمام صفحه» در پنجره ضبط لازم باشد. چرخش صفحه حین ضبط ممکن است نیازمند توقف و شروع دوباره باشد.

## حریم خصوصی و محدودیت آماری
OCR فقط با رضایت کاربر فعال می‌شود؛ متن صفحه برای تحلیل محلی پردازش می‌شود. داده‌های استخراج‌شده ممکن است شامل اعداد غیرمرتبط باشند. این ابزار پیش‌بینی دور بعد یا تضمین برد ارائه نمی‌دهد.
